How a day runs一天怎么运行

It runs before you wake up

你醒来之前，它已经跑完

A plain-Python core handles everything that must be exact: money, filters, scores, ledgers. Claude handles the judgment calls, in one-shot runs with no tools whose answers must fit a schema.

所有必须精确的事情（钱、筛选、分数、账本）都由纯 Python 代码完成；需要判断力的事情交给 Claude，每次都是一次性调用、没有任何工具，回答必须符合固定的 JSON 格式。

  1. 07:30

    Collect, under a hard cap采集，严格封顶

    One Apify run per search group, in your track order. Every run carries its own spending cap, and today's cap spreads your monthly budget across the month.

    每个搜索组跑一次 Apify，按你的方向优先级排序。每次运行都有自己的花费上限，每天的上限把月预算均摊到每一天。

    maxTotalChargeUsd = min(group budget, today's cap − spent)

  2. 07:41

    Drop what you can never take, for free免费筛掉一定投不了的

    Internships, citizenship-only roles, "no sponsorship" if you need it, salary floors, 10+ years for a junior search, AI-training gigs. Each drop keeps its rule, so a wrong one is easy to see and loosen.

    实习、只招美国公民、你需要 sponsor 但对方明确不提供、薪资低于底线、初级求职却要求 10 年以上、AI 数据标注零工。每条都记录是哪条规则筛掉的，错杀一眼就能看到、随时放宽。

    27 dropped · $0.00 · rule and quote kept for each

    完整的 JD 分批交给一次性的 claude -p。每条评审按你这个方向自己的打分标准，给职责、背景、技能、资历四项打分，并逐字引用 JD 和你的资料。

Scores you can audit可以核查的分数

No quote, no score

没有原文引用，就没有分数

  • The model proposes, code decides. JobPilot accepts a review only if every quote occurs verbatim in the posting or in your profile, every component is in range, and the category belongs to the track.
  • 模型提出，代码裁决。只有每条引文都能在 JD 或你的资料里逐字找到、每项分数都在范围内、类别也属于这个方向，评审才会被接受。
  • The score is computed, not asked for: min(fit cap, duties + background + skills + seniority).
  • 分数由代码计算，而不是问模型要：min（封顶分，职责 + 背景 + 技能 + 资历）。
  • Each track has its own rubric. A data-science role is never judged by an ML-engineering yardstick.
  • 每个方向有自己的打分标准。数据科学岗不会用机器学习工程的尺子去量。
  • Edit your rubric and older scores turn stale until they are rescored. They never quietly change meaning.
  • 修改打分标准后，旧分数自动标记为过期，重新评审前不会悄悄改变含义。

Tailoring that never invents不编造的简历定制

Your resume, sharpened. Not rewritten.

打磨你的简历，而不是重写它

  • Your own Word file, edited in place. Only the changed words are rewritten; fonts, spacing and layout stay byte for byte.
  • 直接在你自己的 Word 文件上改。只改动变化的那几个词，字体、间距、版式一个字节都不动。
  • Minor edits on purpose: reorder by the posting's priorities, mirror its nouns only where true, about 3–4 bullets.
  • 刻意只做小改动：按 JD 的重点重新排序，只在属实的地方用 JD 的关键词，大约改 3–4 条。
  • Questions instead of fiction. When a stronger bullet needs a fact you never stated, JobPilot asks you.
  • 缺事实就问你，而不是编。想把一条写得更强、却缺少你没提供过的事实时，它会直接问你。
  • A second pair of eyes. An independent claims audit checks every changed sentence against your profile before you send anything.
  • 再加一道审核。独立的事实审核员对照你的资料逐句检查每处改动，你再决定要不要用。

Install安装

Three steps, about ten minutes

三步，大约十分钟

  1. Add the plugin in Claude Code在 Claude Code 里添加插件

    /plugin marketplace add ZhengShixin/JobPilot
/plugin install jobpilot@jobpilot

  2. Set up from your resume用你的简历完成设置

    In a new folder for your search. Setup reads the resume, asks a few questions only you can answer, proposes role tracks, writes the rubrics and the search plan, and checks the plan for free.

    在一个专门的新文件夹里运行。setup 会读简历、只问几个必须由你回答的问题、推荐求职方向、写好打分标准和搜索方案，并免费验证一遍。

    # terminal
mkdir ~/job-search && cd ~/job-search && claude
# then, in Claude Code
/jobpilot:setup ~/Downloads/my-resume.pdf

  3. Save your Apify token, then run保存 Apify token，然后开跑

    The token goes in through a hidden prompt in your own terminal and never enters the chat.

    token 在你自己的终端里通过隐藏输入保存，永远不会出现在对话里。

    ./jobpilot token set
# back in Claude Code
/jobpilot:daily        # first search and review
/jobpilot:dashboard    # open the dashboard
/jobpilot:schedule     # run every morning

What it costs花费

  • Apify, your account: about $0.005 per posting on the free tier. A focused search of about 80 postings a day is roughly $0.40 a day, with caps per run, per day and per month.
  • Apify（你自己的账号）：免费档每条岗位约 $0.005。每天约 80 条的精准搜索，大约每天 $0.40，每次运行、每天、每月都有上限。
  • Claude, your plan: a batch of about ten job descriptions averages $0.20 at API prices; the free filter removes a large share first.
  • Claude（你自己的额度）：一批约 10 份 JD 按 API 价格平均约 $0.20；免费粗筛会先去掉一大部分。

What it never does它绝不会做的事

  • Submit an application, fill a form or log in anywhere for you.
  • 替你提交申请、填写表单，或者登录任何网站。
  • Send, draft, label or delete email; message anyone on LinkedIn.
  • 发送、起草、标记或删除邮件；在 LinkedIn 上给任何人发消息。
  • Read your Apify token into the conversation.
  • 把你的 Apify token 读进对话。
  • Put a fact on your resume that your profile does not contain.
  • 在简历里写进你资料里没有的事实。

FAQ

Questions people ask

常见问题

Will it apply to jobs for me?它会替我投递吗？

No. It finds, scores and prepares; you submit. Auto-apply bots get flagged by employers and break on every form; a guard hook keeps JobPilot out of email and LinkedIn inside your workspace.

不会。它负责找、打分和准备，提交由你来。自动投递机器人容易被雇主识别，也会在各种表单上出错；工作区里还有守卫 hook，禁止 JobPilot 碰邮件和 LinkedIn。

Which jobs and countries does it cover?覆盖哪些岗位和地区？

Any role family your resume supports (engineering, data, research, quant, analytics…). Postings come from a LinkedIn job index on Apify; locations are configurable, for example "United States" or "London, England, United Kingdom".

你的简历能支撑的任何方向（工程、数据、研究、量化、分析……）。岗位来自 Apify 上的 LinkedIn 岗位索引，地区可以配置，比如 "United States" 或 "London, England, United Kingdom"。

Does my data leave my computer?我的数据会离开我的电脑吗？

Only what each step needs: job descriptions and your scoring profile go to Claude for review, search filters go to Apify. Everything else stays in your workspace folder. There is no telemetry.

只发送每一步必需的内容：JD 和你的打分资料发给 Claude 评审，搜索条件发给 Apify，其余全部留在你的工作区文件夹里。没有任何遥测。

I need visa sponsorship. Does it handle that?我需要 sponsor，它能处理吗？

Yes. Set your work authorization during setup: postings that explicitly say they will not sponsor are dropped for free, and the reviewer flags citizenship or clearance requirements.

可以。在 setup 时填写你的工作身份：明确写着不提供 sponsor 的岗位会被免费筛掉，评审还会标出要求公民身份或安全许可的岗位。

Can I use it without Claude Code?不用 Claude Code 能用吗？

The command line works on its own (pipx install from GitHub): collection, review through the claude CLI, the ledger and the dashboard. The guided setup and tailoring conversations are Claude Code skills.

命令行可以单独用（从 GitHub pipx install）：采集、通过 claude 命令行评审、账本和 dashboard 都能跑。引导式的 setup 和定制简历对话是 Claude Code 的 skill。

Is the referral finder allowed by LinkedIn?校友内推功能符合 LinkedIn 的规定吗？

It uses a third-party Apify actor that collects public profile data, and LinkedIn's terms restrict scraping, so you decide whether to use it. It only runs when you ask, keeps results on your machine, and never contacts anyone.

它使用第三方 Apify actor 采集公开资料，而 LinkedIn 的条款限制抓取，所以用不用由你决定。只有你主动发起才会运行，结果只留在你的电脑上，也从不联系任何人。
